## Phase 5 · 觉醉品牌战略升级（2026-09-03 完成）

> 注：本节为 2026-09-03 战略对齐，确立觉醉核心叙事与扩展路径。Phase 0-4 仍按下方原路线图推进。

### 5.1 战略定位

- **产品定位**：觉醉 · 感官情绪探索游戏（不是工具，是镜中自观+调酒仪式+情绪反馈的循环玩物）
- **品牌名**：觉醉 JueZui（取代旧"Y.Mine / 人格调酒"）—— 调酒+心理+玩三合一
- **核心叙事**：镜中自观 → 调酒仪式 → 情绪反馈 → 感官在夜里循环

### 5.2 用户画像

- 50% 主力：25-32 都市创意人（产品/设计/内容/AI 工程师）
- 35% 泛用户：22-38 体验派（MBTI/调酒/香氛/冥想任何一项感兴趣）
- 15% 长尾：心理/玄学/调酒从业者

### 5.3 竞品参考

| 类型 | 代表 | 借鉴点 |
|---|---|---|
| 情绪冥想 | Headspace / Calm | 引导式日/夜循环 |
| 调酒工具 | Cocktail Flow | 配方卡片 + 风味画像 |
| 沉浸音景 | Endel | AI 实时生成 + 生理节律 |

| 情绪记账 | 叨叨记账 | 情绪 + 实体行为闭环 |

### 5.4 视觉对标

- **Spotify**（沉浸+深绿）→ 推到深空暗紫
- **PlayStation**（暗夜+情绪）→ 情绪光斑
- **ElevenLabs**（AI 沉浸+电影风）→ 渐变光晕
- **主推语言**：「深空暗紫 + 情绪光斑 + 紫金点缀」

## Phase 0 · 补功能缺口（→ M1 · 9/9 完整）

### 0.1 ChessPage 国际象棋局
- **现状**：仅展示四维度映射数据，无交互
- **任务**：落子交互 + 棋风人格推导（E/I·N/S·T/F·J/P → 向量）+ 接入 personaFusion
- **依赖**：四维度映射规则已定义（见 project_memory）
- **验收**：能完成一局棋风采集，输出棋风向量，融入调酒推荐
- **风险**：完整棋局 AI 复杂度高，考虑用关键节点选择式交互降级

### 0.2 ExplorePage 五维内容深化
- **现状**：5 维度（产品/商业/金融/合作/业务）为泛占位文案
- **任务**：替换为真实白皮书/商业计划书/财务模型/合作手册/技术架构
- **依赖**：⚠️ **需要用户提供真实业务信息** —— 内容来源在用户
- **验收**：每维度有实质可读内容，非占位

## Phase 1 · 工程化降债（→ M2 · 可发布质量）

### 1.1 chunk 拆分
- **现状**：单包 1.6MB，build 持续警告 >500kB
- **任务**：路由级 `React.lazy` + 引擎 `manualChunks`（timeEngine/cocktailEngine/feedbackEngine 分包）
- **依赖**：无
- **验收**：首屏 <500kB，build 无警告

### 1.2 错误边界 + Suspense
- **依赖**：1.1（lazy 后必须有 Suspense）
- **任务**：ErrorBoundary 组件 + 各路由 fallback 加载态
- **验收**：局部崩溃不白屏，有加载态

### 1.3 监控埋点上线
- **现状**：trackFeedback 各节点已定义但只 console.debug
- **任务**：接真实上报通道（选型：自建 / Sentry / 其他）
- **依赖**：无（但需决定后端）
- **验收**：DEV 全量、线上 1% 采样、error 级始终输出
- **风险**：需选上报后端

## 关键风险

1. **ExplorePage 内容来源在用户** —— Phase 0.2 阻塞，需用户提供真实业务信息
2. **Phase 2 需要真实用户** —— 反馈数据要发布后才能积累，M2 发布是 M3 前提
3. **Phase 3 后端选型** —— 影响工程量，建议 M2 后再决定是否需要
4. **ChessPage 棋局 AI 复杂度** —— 完整国际象棋 AI 过重，倾向用关键节点选择式交互
